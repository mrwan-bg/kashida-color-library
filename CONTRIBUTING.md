# Contributing

Thank you for your interest in contributing to Kashida Colors Showcase.

## Reporting bugs
- Search existing issues before opening a new one.
- Use the Bug Report issue template.
- Include the WordPress and PHP versions, clear reproduction steps, and the expected and actual behavior.
- Do not include passwords, private customer data, or production secrets.

## Suggesting features
- Use the Feature Request issue template.
- Describe the use case and the expected result.

## Code contributions
- Keep changes focused and compatible with the plugin's supported WordPress and PHP versions.
- Follow WordPress coding and security practices.
- Validate and sanitize input, escape output, and use capability checks and nonce verification for administrative actions.
- Avoid introducing unnecessary external services or tracking.
